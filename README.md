## ⚙️ Getting Started

Want to explore or run the portfolio locally? Follow these steps.

### Prerequisites

Make sure you have the following installed:

- Git
- Visual Studio Code (recommended)
- A modern web browser
- Live Server extension (optional)

### Step 1 — Clone the Repository

```bash
git clone https://github.com/rajsangani2000-byte/Portfolio.git
```

### Step 2 — Navigate to the Project

```bash
cd Portfolio/main
```

### Step 3 — Open in Visual Studio Code

```bash
code .
```

### Step 4 — Launch the Website

**Option 1: Using Live Server**

1. Install the Live Server extension in VS Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.
4. Your portfolio will open in the browser.

**Option 2: Using Python HTTP Server**

Run the following command:

```bash
python -m http.server 8000
```

Open the following address in your browser:

```text
http://localhost:8000
```

> **Important:** This is a static HTML implementation. No npm installation or frontend build process is required for the current setup.
