## 📖 About the Project

This repository contains my personal portfolio website, designed to introduce who I am, showcase my creative work, highlight the technologies I explore, and document my journey as a developer.

Rather than being just a collection of projects, this portfolio represents my approach to learning, experimenting, designing, and building meaningful digital experiences.

**🎯 My Philosophy:**

> Learn something new. Practice what you learn. Repeat until you create something meaningful.

## ✨ Key Features

- 👨‍💻 **Personal Introduction:** A dedicated hero section introducing Raj and my approach to design and development.
- 🙋 **About Me:** A personal introduction highlighting my interests and creative journey.
- 🛠️ **Services Showcase:** Sections covering Web Development, UI/UX Design, App Development, and Video Editing.
- 🚀 **Selected Projects:** A visual showcase of my development projects with links to their respective live experiences.
- 💡 **Creative Inspiration:** A dedicated section featuring personalities who inspire my creativity, ambition, discipline, and continuous learning.
- 💻 **Technology Showcase:** A visual collection of development tools, design applications, and AI platforms I explore.
- 🎬 **Interactive Animations:** GSAP-powered animations, scroll effects, transitions, and interactive elements.
- 📱 **Responsive Layout:** A layout designed to adapt to desktop, laptop, tablet, and mobile screens.
- 🌐 **Social Connectivity:** Direct access to my GitHub, LinkedIn, Instagram, and email.

## ⚙️ Run Locally

You can run this portfolio locally on your computer without installing a frontend framework.

### 📋 Prerequisites

- Git
- A modern web browser
- Visual Studio Code (recommended)

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/rajsangani2000-byte/Portfolio.git
```

### 2️⃣ Navigate to the Project

```bash
cd Portfolio/main
```

### 3️⃣ Open in Visual Studio Code

```bash
code .
```

### 4️⃣ Run the Website

**Option 1: Live Server**

1. Install the Live Server extension in VS Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.

**Option 2: Python HTTP Server**

```bash
python -m http.server 8000
```

Open your browser:

```text
http://localhost:8000
```

> 💡 No npm installation or build process is required for the current static HTML implementation.
